## Висновок

Критичних технічних блокерів індексації не виявлено. Усі дев'ять URL із sitemap доступні для Google, повертають HTTP 200, мають унікальні метадані, один H1, self-canonical і змістовний початковий HTML. `robots.txt` не блокує сторінки або ресурси.

Статус «Проскановано — наразі не проіндексовано» для `/napryamky` найімовірніше пов'язаний із новизною домену та повторною оцінкою сторінки Google, а не з технічною помилкою сайту. Масово змінювати URL, canonical або контент не потрібно.

## Перевірені технічні сигнали

- `sitemap.xml` містить лише канонічні URL і збігається з реальною структурою сайту.
- `robots.txt` дозволяє індексацію та містить посилання на sitemap.
- Версія `www` постійно перенаправляється на основний домен.
- URL зі слешем наприкінці постійно перенаправляються на канонічну версію без слеша.
- `/logo-variants` відсутня у sitemap і має `noindex, nofollow`.
- Навігація та посилання між напрямками присутні як звичайні HTML-посилання.
- Назви `RUBIKON BUILD`, `Rubikon Build`, `rubikonbuild` і `Рубікон Білд` узгоджені через структуровані дані організації.
- Не додаємо вигадану адресу, рейтинг або профілі `sameAs`, доки немає підтверджених офіційних даних.

## Google Analytics 4

Measurement ID: `G-WYRXJV71WG`

Підтверджено:

- до згоди користувача GA4 не завантажується;
- після згоди скрипт `gtag.js` успішно додається;
- помилок CSP або JavaScript після запуску не виявлено;
- події кліків по контактах надсилаються як `contact_click`;
- додано явне відстеження `page_view` при переходах між сторінками через Next.js без повного перезавантаження;
- початковий `page_view` не дублюється.

Остаточну появу подій у Realtime/DebugView потрібно перевірити у приватному кабінеті GA4 після публікації, оскільки він доступний лише в авторизованому акаунті власника.

## Наступні дії

1. Після публікації відкрити сайт, дозволити аналітику і перейти між 3–4 сторінками.
2. У GA4 відкрити Realtime та перевірити `page_view` і `contact_click`.
3. У Search Console не надсилати повторні запити щодня. Перевірити `/napryamky` через 7–14 днів.
4. Після появи реальних проєктів і фотографій посилити сторінки напрямків кейсами — це буде сильнішим SEO-сигналом, ніж косметичні зміни тексту.
