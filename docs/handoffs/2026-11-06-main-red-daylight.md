## Успадковані червоні перевірки

- **LCP HOME у Nightly:** 3,66 с при межі 3,6 с. Історія Nightly показує реальний ріст ваги сторінки: 3,35 с (до 03.11) → 3,46 с (#299, +94 КБ) → 3,66 с (#301, нове фото HOME `hero-frame-photo-v1-768w`, 123,6 КБ). Потрібне рішення власника: стиснути фото (з того ж WebP q75 дає 91 КБ, але це повторне стиснення без оригіналу) або підняти межу LCP HOME.
- **`home-proof-contour:2122`:** один флейк приблизно на 25 запусків Main (телефон, зсув `hv2-frame-side` під час появи аркуша). Не стосується цих змін.
