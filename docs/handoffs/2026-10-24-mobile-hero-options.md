[Відкрити галерею A/B/C](../../design-assets/reviews/mobile-hero-options/index.html). На телефоні гортати картки вбік. Є320/390/430 px, light/dark, усі5 сцен хаба й збільшення тексту HOME/About до200%. Для швидкого вибору: «Напрямки B, головна C, про компанію A».

| Головна | Чинний H1 як контроль | Новий рендер, повний проліт із масивною фермою | Та сама нова ферма крупніше, колони частково поза кадром | **B** для цілісного простору; **C**, якщо хочеться максимально сильного першого акценту |
| Про компанію | Новий відкритий каркас | Інший новий рендер — каркас з облицюванням | Крупний конструктивний кут рендера B | **A** для чесної предметності будівництва; **B** для більш завершеного й солідного образу |

About A/B/C не використовують H1 головної. Згенерованих людей немає. Усі нові рендери чесно позначено «Ілюстрація», це не фото виконаних компанією об’єктів. Джерела й фінальні завдання генерації: [render-prompts-and-sources.md](2026-10-24-mobile-hero-render-sources.md).

Варіанти B/C у галереї — браузерні симуляції, а не автоматично обраний фінальний дизайн. Поточний код Draft PR має новий About A; HOME і зум напрямків чекають вибору власника. Самі кадри напрямків узято з чинних ілюстрацій, без нової генерації. Макет тексту, шапка й кнопки збережені. Сильний зум свідомо показує фрагмент; він не обіцяє повну споруду.

## Перевірки

144 підсумкових знімки браузера:126 Chromium (3ширини×2теми; у хабі всі5сцен),6 із текстом200% і12 WebKit для HOME/About390. JavaScript errors0; горизонтальний overflow0; горизонтальне переповнення hero-тексту0. H1/hero/CTA geometry між варіантами при звичайному тексті однакова. На320px із200% текстом може знадобитися вертикальна прокрутка — це очікувано, не імітація системного Dynamic Type. Галерея показує стабільні кадри, реальну плавність crossfade треба дивитися у preview сайту. Оригінальні функціональні timing/pause/reduced-motion перевірки напрямків з попереднього етапу не замінено статичними знімками.

About A повторно перевірено окремо:12 Chromium-знімків320/375/390/430/768 у двох темах;6 WebKit320/390/430;3 збільшення тексту;2 reduced-motion. TypeScript/ESLint і функціональні hydration/one-poster/no-video тести пройшли. Виміряні текстові зони About A390 у двох темах без порушень заданих контрастних порогів; це не повний WCAG-аудит.

## Вага й статус

About A: WebP480 —51 918B,768 —114 752B,1024 —180 124B. Проти тимчасового повтору HOME це+10 416B наDPR1 та+39 938B наDPR3. Нового відео немає; preload/hydration узгоджені й не запитують старий H1 наAbout. Для інших кандидатів traffic/LCP ще не заявляємо: галерея використовує знімки й data-URI симуляції. Після вибору потрібні фінальні responsive AVIF/WebP та перевірка холодного завантаження.

Знімки завантажуються лише при відкритті галереї. Перед merge цей review-каталог треба прибрати або явно погодити його збереження. Production, DEC-18 snapshots і main не змінено.
