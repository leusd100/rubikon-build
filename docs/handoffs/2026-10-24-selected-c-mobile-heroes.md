У фінальних записах помилокJS/горизонтального overflow немає. Зони заголовка/lead/CTA на320/390/430 в обох темах проходять виміряні контрастні пороги; це не повнийWCAG-аудит. Пройшли17цільових browser tests (5нерелевантних комбінацій пропущено), TypeScript/ESLint/production build. SSR/hydration зберігає одинposter і його кадрування. ЕталониDEC-18 не змінено.

## Уточнення за iPhone-скриншотом власника: м’якший About

![About до / після](media/about-softer-before-after.jpg)

Тільки About ≤600px: середній stop затемнення .88 → .58, м’який перехід .85, повний графіт пізніше. Видимі бетонні опори, підлога й креслярські лінії. Дрібні breadcrumb/eyebrow світліші; на першому візиті градієнт піднімається разом із текстом над cookie-панеллю. Відступ CTA → стрілка 24 → 12px, зона натискання 44×44px і Safari tail збережені. HOME та решта маршрутів у цьому уточненні без змін.

Перевірено Chromium320/375/390/430/768 у двох темах, WebKit320/390/430,200%текст і reduced motion. JS/overflow помилок немає. Виміряні видимі написи на320/390/430 проходять пороги3:1 для великого й4.5:1 для дрібного тексту; це не повнийWCAG-аудит. Перший візит перевірений окремо. 8focused browser checks пройшли (3нерелевантнікомбінації skipped), build пройшов. Геометричний тест уточнено лише для нового відступу About; visual snapshots не змінювалися.

Медіафайл той самий:78 656B наDPR3,18 344B наDPR1; одинposter, без phone-video, measuredChromiumCLS0. Це емуляція, потрібен повторний перегляд на фізичному iPhone12.
