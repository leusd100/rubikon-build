# Лабораторія продуктивності

## Базова лінія

- **Production до 27.10** — `docs/performance/debugbear-2026-10-27/` (21 сторінка, 485 прогонів, Lighthouse JSON). RUM і CrUX
  відсутні: трафіку замало, тож поля CrUX порожні.
- **Production після 27.10** — `pagespeed-monitor.yml`: HOME після кожного деплою; щодня по сторінці на шаблон (артефакт
  `pagespeed-*`, Step Summary). PSI — Lighthouse 13, симульоване тротлінгування.
- **Бюджет-воротар** — `pnpm test:lighthouse` (Nightly, `lighthouserc.cjs`): Lighthouse 12.6, simulate, 5 прогонів, медіана.

## Локальний вимір (до і після — однаково)

```bash
pnpm build
node scripts/perf/lhci-server.mjs --port 4174 &        # brotli, як у Cloudflare
node scripts/perf/lab-lighthouse.mjs --url http://127.0.0.1:4174/ --runs 5 --throttling devtools
node scripts/perf/lab-lighthouse.mjs --url http://127.0.0.1:4174/ --runs 5                      # simulate = як Nightly
node scripts/perf/trace-style-layout.mjs --url http://127.0.0.1:4174/ --runs 5 [--invalidation]
```

- `devtools` = профіль DebugBear Mobile (150 мс RTT, 1,6 Мбіт/с, CPU ×4, 412×660 @2,625). Сума LCP збіглася з production
  (3574 vs 3568 мс), **частини — ні**: локально немає TTFB і HTTP/3-пріоритетів. Порівнюй гілку з `main` на одній машині.
- 5 прогонів, медіана. Дві збірки одночасно — різні порти (`--port 4274` …; апстрім займає порт +1000).
- Зупиняй сервери за портом (`lsof -ti tcp:4174 | xargs kill`), не залишай їх між задачами.

## Уже перевірено — не повторюй без нового доказу (27.10, HOME mobile)

| Гіпотеза | Експеримент | Результат |
|---|---|---|
| Прибрати примусові перерахунки стилю (`useRoom`, `ProcessMotion`) зменшить TBT | правка + 5×5 трейсів | forced 239 → 157 мс, але стиль+розкладка 783 → 791 мс, блокування 775 → 756 мс (шум). **Відхилено**: перший перерахунок після гідратації платить той, хто першим читає розкладку |
| `body:has(...)` змушує перераховувати все дерево | нейтралізовано в одноразовій збірці | 780 мс проти 783 мс. **Відхилено** |
| LCP-зображення чекає за ~45 модульними скриптами (TTFB зображення 900 мс у production) | лише з waterfall DebugBear | **Не перевірено**: локальний HTTP/1.1 не відтворює HTTP/3-пріоритети Cloudflare; потрібен вимір на preview (OK власника) |

Відоме, але не «тиха оптимізація» (рішення власника): 6 передзавантажених шрифтів (~125 КБ) конкурують з LCP-зображенням на
мобільному — свідомий вибір проти зсуву героя (`app/layout.tsx`).
